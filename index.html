What is HTML?

HTML stands for HyperText Markup Language. It uses elements called tags to describe content to the browser. A heading, paragraph, link, or image can each be represented by an HTML element.

EXAMPLE 
                                    <h1 >Hello, world!</h1 >
<p >I am learning to code.</p >
